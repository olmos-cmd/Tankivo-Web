Hinweis zur App und Datenquelle

Tankivo ist eine unabhängige Anwendung zur Anzeige von Kraftstoffpreisen. Die Preisdaten werden über die freie API von Tankerkönig unter der Lizenz CC BY 4.0 bezogen. Die Ursprungsdaten stammen von der Markttransparenzstelle für Kraftstoffe (MTS-K) des Bundeskartellamts. Tankivo ist keine offizielle App dieser Behörden.
